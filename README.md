# Minha Meta — Novo Tema

Aplicativo de calculadora de juros compostos com tema preto, grafite e dourado.

## Publicar no GitHub Pages

1. Envie o `index.html` para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação.

O aplicativo funciona em um único arquivo e salva a última simulação no navegador.
